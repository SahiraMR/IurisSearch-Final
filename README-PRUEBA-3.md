# Prueba 3: formulario PrimeFaces

El diagnóstico confirmó que «Buscar en:» es un fieldset plegado. Esta versión lo expande antes de escribir, conserva el radio «Texto completo» y trata de seleccionar Sala de Casación Penal desde el panel visual del menú.

Ejecutar desde la carpeta con `package.json`:

```powershell
npm install
npm run probar:oficial
```

Si devuelve `filtro_penal_pendiente`, comparte el JSON de la terminal: todavía debemos identificar el panel exacto. Si devuelve `consulta_enviada_pendiente_validacion`, comparte filas y enlaces para validar si realmente hay providencias. No se ha verificado contra el portal en este entorno.
