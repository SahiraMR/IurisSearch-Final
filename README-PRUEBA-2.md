# Prueba 2: consulta real al portal oficial

Desde la carpeta del proyecto, ejecutar `npm run probar:oficial`.

La prueba selecciona Sala de Casación Penal, marca Texto completo, escribe «hurto», pulsa Buscar y recopila hasta diez filas visibles y enlaces para diagnóstico. No descarga documentos ni envía resultados a Gemini. Si el portal cambia o bloquea la automatización, mostrará un error que necesitamos revisar. No evadir CAPTCHA ni restricciones del portal.

Comparte el JSON resultante (sin datos personales) para validar el formato de las sentencias y desarrollar la extracción estructurada.
